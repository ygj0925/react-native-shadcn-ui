# MindFlow v1.0 — AI 驱动的全能生活管家

## 概述

将现有 react-native-shadcn-ui 项目从一个 AI 聊天 Demo 升级为 **MindFlow** — 一款 AI 原生的个人效率工具，集成日程管理、笔记系统、习惯追踪、目标管理四大模块，以 AI 为核心差异化，通过订阅制 (SaaS) 盈利。

## 问题

当前项目是一个功能分散的 Demo 应用：
- AI 聊天功能独立存在，与其他模块无联动
- 日历仅支持查看，无法管理任务
- 工作台、收藏页为空壳
- 无用户账户系统，数据仅存本地
- 无商业化能力

用户需要一个**能将日程、笔记、习惯、目标串联起来的智能系统**，而不是散落的工具。市场上没有产品同时做到"AI 原生"和"功能全面"。

## 目标用户

25-40 岁知识工作者，追求效率但不想折腾复杂工具。使用场景：日常工作管理、个人成长追踪、生活规划。

## 拟定方案

### 产品定位
- **名称**: MindFlow (心流)
- **一句话**: AI 驱动的全能生活管家
- **核心差异**: AI 原生 + 功能全面 + 简洁优雅

### 六大核心模块

| 模块 | 描述 | 优先级 |
|------|------|--------|
| 今日首页 (Dashboard) | 每日入口，串联所有模块的枢纽 | P0 |
| 日程管理 (Calendar) | 基于现有日历扩展，支持任务关联、AI 自然语言创建 | P0 |
| 笔记系统 (Notes) | 富文本编辑 + AI 自动分类/摘要/标签 | P0 |
| 习惯追踪 (Habits) | 打卡 + 数据可视化 + AI 习惯-效率关联分析 | P1 |
| 目标管理 (Goals) | OKR 模式 + AI 拆解建议 + 进度追踪 | P1 |
| AI 智能中心 | 多模型支持、Function Calling、个人知识库 | P0 |

### 技术决策

| 决策项 | 选择 | 理由 |
|--------|------|------|
| 后端 | Supabase | Auth + DB + Storage + Realtime 一体化，开发速度快 |
| 数据库 | PostgreSQL (Supabase) | JSONB 支持富文本，全文搜索内置 |
| 支付 | RevenueCat | iOS/Android IAP 统一管理，订阅状态同步 |
| 编辑器 | @10play/tentap-editor | 基于 TipTap，React Native 原生，支持富文本 |
| 图表 | react-native-gifted-charts | RN 生态最成熟的图表库 |
| AI 模型 | Mimo (默认) + OpenAI/Claude 可选 | 多模型路由，成本可控 |
| 本地存储 | MMKV + SQLite | MMKV 存配置/状态，SQLite 存结构化数据 |
| 日期处理 | date-fns | 轻量、tree-shakeable、函数式 |

### 盈利模式

订阅制 (SaaS):
- **免费版**: AI 10次/天、笔记10条、习惯3个、目标1个、无云同步
- **Pro (¥28/月, ¥268/年)**: 无限 AI、无限笔记/习惯/目标、云同步、数据导出
- **团队版 (¥68/人/月)**: Pro 全部 + 团队协作 + 共享日程 + 管理后台

### 开发周期

3 个月+，分 4 个阶段：
1. 第1个月: 核心基础 (用户系统 + 笔记 + 习惯)
2. 第2个月: AI 能力 + 日程 (AI 增强 + Dashboard)
3. 第3个月: 商业化 (订阅体系 + 目标管理 + 数据洞察)
4. 第4个月: 上线准备 (优化 + 测试 + 提审)

## 不在范围内

- v1.0 不做团队协作功能 (v2.0 考虑)
- v1.0 不做 Web 端 (仅移动端)
- v1.0 不做实时协同编辑
- v1.0 不自建 AI 模型 (使用第三方 API)
- v1.0 不做社交/分享功能

## 风险

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| AI API 成本超预期 | 高 | 免费版限制次数，Pro 版设合理上限，监控用量 |
| Supabase 免费额度不足 | 中 | 评估用量，必要时升级 Pro plan |
| 富文本编辑器 RN 兼容性 | 中 | 先做 MVP (纯文本)，再迭代富文本 |
| App Store 审核拒绝 | 中 | 提前研究审核指南，避免敏感功能 |
| 用户付费意愿低 | 高 | 免费版足够好用建立习惯，付费版提供明确价值 |
