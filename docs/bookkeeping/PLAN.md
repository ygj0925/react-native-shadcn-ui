# 简账：免费记账 App 完整规划与交付清单

编制日期：2026-11-17。目标项目：react-native-shadcn-ui。保留 MindFlow 原有功能，新增独立记账工作区。产品工作名「简账」，使用独立品牌、图标和界面，不复制第三方素材。所有规划能力均免费，无会员、订阅、广告解锁、额度付费墙。

## 1. 调研依据与边界

依据鲨鱼记账开发者发布的 [标准版说明](https://apps.apple.com/cn/app/id1079718756)、[Pro 版说明](https://apps.apple.com/cn/app/id1163515895) 及[官网](https://shayujizhang.com/)。公开说明确认快速记账、消费趋势、备注提示、云同步、提醒、小组件，以及 Pro 的饼图、搜索、解锁密码、金额隐藏、预算、记账日历、自定义账期、定时记账、标签、皮肤。公开描述不能证明全部 VIP 隐藏页面、平台差异和最新灰度能力，故不能宣称对未见过的功能做到逐项完全相同。以下以明确的功能矩阵作为验收合同，资产、多账本、共享、导入导出作为本产品补充能力。

## 2. 现状审计

- 前端：Expo SDK 54 / React Native 0.81 / React 19，Expo Router、Zustand；原有笔记、习惯、日程、任务和 Supabase 登录同步。
- 原有订阅代码属于 MindFlow；记账模块不引用 useFeatureGate、RevenueCat 或 Supabase。旧业务不自动删除或迁移。
- 指定服务 `D:\project\guard-find\guard-find-backend` 目前是管理端、房源、小程序和 OA 服务，尚未发现个人记账模块；小程序登录是微信 code，不能拿 RN 账号直接调用。
- 同目录 `guard-find-server` 是另一个服务，已有 `/app/auth`、`/app/ledger`、`/app/budget` 和共享账本；不能因存在这些接口就擅自替换指定后端。后端选择等待用户确认。
- 两个后端均存在其他业务；不得覆盖未提交修改，不提交部署，不执行数据库迁移或真实短信发送。

## 3. 产品结构与交互

入口位于 MindFlow 今日页「简账」；记账工作区五个栏目：明细、图表、预算、资产、设置。主色暖金，纸白背景，深墨文字；金额等宽数字；支出/收入同时用文字和符号表达。暗色与亮色使用相同层级。大屏最大内容宽度 960，手机底部操作区避开安全区；表单可滚动、键盘不挡保存。

明细：账本切换 → 月份/日期/分类/关键字筛选 → 按日聚合 → 点击编辑；固定「记一笔」按钮。录入选择支出、收入或转账，再输入金额、分类、日期、账户、备注和标签。允许补记；保存成功后立即更新明细、预算、图表、资产，不弹付费框。删除必须明确确认。

图表：月/年收支、净结余、分类排名与占比、每日趋势；空数据展示真实空状态。日历点击筛选当天，不生成演示账单。预算按月总额和分类分别设置，80% 提醒、100% 超支；转账不进入收支或预算。

## 5. 数据模型与金额规则

Book(id,name,currency,archived)，Account(id,name,kind,openingBalanceCents,archived)，Category(id,name,type,archived)，Entry(id,bookId,type,amountCents,categoryId,accountId,toAccountId,date,note,tags,updatedAt,deletedAt)，Budget(bookId,month,categoryId,limitCents)，Recurring(id,template,frequency,nextDate,enabled)，Settings(hideAmounts,theme,billingStartDay)。

所有 ID 为字符串。金额一律以整数分存储与运算；用户输入最多两位小数、禁止负数和非有限数；账户期初允许负数表示负债。转账对两个账户一次性记一笔，净资产不变；编辑和删除通过重新聚合余额反映，不反复累加。所有统计过滤删除记录。业务日期使用本地 YYYY-MM-DD，不以 UTC 截断本地日期。预算按账本/月份/分类唯一。周期实例键为规则 ID + 到期日，重复启动不重复入账。
